Logic map

How the randomizer decides what you can reach. Progress is a chain of milestones: each needs earlier milestones plus some items. Every location needs a set of milestones and items. Pick the items you hold to see what opens up, and switch the world options to see how they change the chain.

Green: done. Gold: open, missing items in red. Hover an item above to see where it's needed. Click a milestone for details.

Locations

The logic is deliberately conservative: a location counts as reachable only once you hold everything that could plausibly be needed for it, often everything for the whole dungeon or area. It has not been checked against the remake yet. Songs, the Ocarina, bottles, boss rewards, Small Keys and Boss Keys stay where the original game has them, so they are assumed and never shown as requirements. With No logic selected in the app, none of this applies.
